# 未完待续

三幕之后，先展开「continue / 未完待续」与片尾链接，再退回一张静谧的 macOS 桌面。片尾文字留在「下一幕.md」便笺窗口内，保持在最后一帧。

桌面使用色板绘制的山峦壁纸、半透明菜单栏和 Dock；均为布景，不模拟真正的系统操作。Dock 包含 Finder、WezTerm、Sublime Text、Chrome、ChatGPT、IINA、网易云音乐、Keka、Rectangle、LaunchNext、KeyCastr 与 Omi录屏专家。所有 App 图标直接取自本机安装包。

菜单栏分别展示 Alfred、Rime（鼠须管）、Karabiner-Elements、KeyboardHolder、Bob、CC Switch、KeepingYouAwake，使用各应用原始菜单栏图形作为蒙版，不再用文字或近似 SVG 代替。图标出处与未能确认的当前状态见 `icons/SOURCES.md`。

便笺左侧停留，右侧显出 WezTerm 窗口，逐字输入 `brew upgrade`；输出依次展示 neovim（nvim）、tmux、fzf、eza、starship、yazi、uv、ruff 与 lazygit 的升级完成状态。仅为预设动画，不调用 Homebrew 或执行系统命令。横屏保留三个示意文件夹，竖屏优先保留便笺、终端与完整 Dock。

Dock 图标为本机应用公开图形的 128px 静态副本，菜单栏使用原始模板图形，随 continue 分包预热，不读取或展示真实桌面、文件、通知、聊天、账号、使用记录与网络配置。不展示迅雷、FlClash、通信、VPN、远程连接及数据库工具。菜单栏时间为固定布景时间。

所有入场动作由场景主时间线控制，支持暂停、重播、跳章；竖屏改为上方便笺、下方终端与 Dock，为播放控制条留出空间。减少动态效果时只做淡入。

“片尾之后”通向 GitHub；“回到主页”通向 https://navydev.top/。
